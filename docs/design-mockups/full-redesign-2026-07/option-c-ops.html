Option C - ops-first

The app is built around the floor. Management views are generated from captured activity.

This option is best if the main risk is adoption by operational staff. The first-class destination is Floor, not Kitchen. Kitchen, Bar, Roastery, and Ecommerce are activity workspaces inside it.

What this kills

  • OperateRenamed to Floor because it is clearer for staff.
  • Kitchen linksLocal activity navigation replaces five primary nav items.
  • Dashboard-firstCapture and review are more important than viewing charts.
  • KeptManagement visibility, but it is downstream of clean capture.

Best-practice argument

Operational apps work when the capture path is obvious and touch-friendly. This option reduces contributor confusion and makes manager visibility a result of normal work.

Critical risk

This may overfit the first ops module. It is strongest only if Kitchen, Bar, Roastery, and Ecommerce are the adoption center of MOS.
